# SalesLens AI

**Turn sales data into clear business insights.**

SalesLens AI is a lightweight sales-intelligence product designed to turn messy sales data into understandable business signals.

## Current product
- Premium responsive SaaS-style workspace
- CSV upload and demo dataset
- Automatic detection of revenue, date, product and region fields
- Revenue and transaction KPIs
- Revenue trend visualization
- Product revenue mix
- Automatic business signals
- Executive summary generation and copy action
- Responsive desktop/tablet/mobile layout
- Browser-side analysis for the core MVP

## Product direction
SalesLens is being built in layers so the first version remains fast and simple while the architecture can later support:

1. Excel ingestion
2. AI-powered natural-language analysis
3. Saved workspaces and datasets
4. Authentication and team accounts
5. Recurring reports and exports
6. Usage limits and paid plans
7. Secure server-side AI processing
8. Billing and subscription management

## Technology
- HTML5
- CSS3
- Vanilla JavaScript
- Chart.js
- GitHub

## Privacy principle
The core MVP processes the uploaded CSV in the browser. Sensitive customer data should not be sent to a third-party AI provider until an explicit secure server-side architecture is implemented.

## Local use
Open `index.html` for the marketing/dashboard experience. The project is static and can be deployed to any static hosting provider.
