# SalesLens AI

**Turn sales data into clear business insights.**

SalesLens AI helps teams upload sales data, explore key metrics, identify trends, and turn raw numbers into clear business insights.

## MVP
- CSV upload
- Automatic sales metrics
- Interactive dashboard
- Sales trend charts
- AI-ready insight architecture
- Report workspace

## Stack
- HTML
- CSS
- Vanilla JavaScript
- Chart.js

The first release is intentionally lightweight and privacy-friendly: data analysis happens in the browser for the core dashboard experience.
